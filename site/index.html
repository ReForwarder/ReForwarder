FAQ

Hosted, answered.

Is the hosted version free?

No — hosted is a paid subscription because we run the infrastructure for you. The self-hosted edition stays free under AGPL-3.0.

When does it launch?

Soon. Use the button above to open the hosted app, and watch the GitHub project for announcements.

Can I move between hosted and self-hosted?

Yes. It's the same open-source engine and the same API, and your data can be exported, so you can start hosted and self-host later — or the reverse.

Do I still use my own domains?

Yes. You verify your sending domains and publish SPF, DKIM and DMARC records, just like self-hosted.
